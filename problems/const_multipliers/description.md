Multiplying by a constant never needs a multiplier. Write each product as a sum or difference of shifted copies, and choose the form with the fewest adders (canonical signed-digit recoding).

### Interface

| Port | Direction | Width |
|------|-----------|-------|
| `x` | input | 8 |
| `m7` | output | 16 |
| `m10` | output | 16 |
| `m255` | output | 16 |
