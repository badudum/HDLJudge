A number of any length streams in one bit at a time. Is it divisible by 5 so far? This interview favourite reduces to a 5-state FSM.

### Interface

| Port | Direction | Width |
|------|-----------|-------|
| `clk` | input | 1 |
| `rst` | input | 1 |
| `valid` | input | 1 |
| `bit_in` | input | 1 |
| `d5` | output | 1 |
