Count to six without an adder: a 3-bit shift register with an inverted feedback visits 2n states, and each state is decodable with a single 2-input gate.

### Interface

| Port | Direction | Width |
|------|-----------|-------|
| `clk` | input | 1 |
| `rst` | input | 1 |
| `en` | input | 1 |
| `q` | output | 3 |
| `tick` | output | 1 |
