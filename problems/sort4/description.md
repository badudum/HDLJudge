Sort four bytes in one combinational step using a **sorting network**: a fixed arrangement of compare-and-swap units that sorts every input.

### Interface

| Port | Direction | Width |
|------|-----------|-------|
| `in0` | input | 8 |
| `in1` | input | 8 |
| `in2` | input | 8 |
| `in3` | input | 8 |
| `out0` | output | 8 |
| `out1` | output | 8 |
| `out2` | output | 8 |
| `out3` | output | 8 |
